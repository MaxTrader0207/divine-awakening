## 劍俠技能（v1.37 起）

| id | 名稱 | 說明 |
|---|---|---|
| `sword_strike` | 快劍 | 前方快速劈砍，第三下變突刺 |
| `sword_qi` | 劍氣斬 | 貫穿直線的劍氣 |
| `swift_step` | 凌波微步 | 疾步穿過敵陣，沿路敵人受傷並緩速（典故：武俠小說的輕功身法） |
