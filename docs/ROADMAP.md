# MVP 路線圖（10 週）

假設：一人開發 + AI 協作，每週約 20~25 小時。每週結束版本號 +0.1。
✅ 完成　🟡 進行中　⬜ 未開始

## MVP 範圍
- **做**：主城、新手草原、三層副本（各一首領）、法師（普攻＋4 技能）、AUTO、6 小怪＋3 首領、6 裝備欄＋稀有度＋強化、金幣商店、藥水、本機存檔
- **不做**：真錢商城、多人、多職業、迷霧森林以後的野外
