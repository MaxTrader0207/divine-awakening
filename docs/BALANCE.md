## 裝備

- 掉落率：小怪 18%（普通 60 / 精良 28 / 稀有 10 / 史詩 2）；首領必掉 2 件精良以上（精良 50 / 稀有 38 / 史詩 12）。
- 稀有度倍率：普通 1.0、精良 1.3、稀有 1.7、史詩 2.2。強化每 +1 全屬性 +8%。
- 強化成功率：+1~+2 100%、+3 90%、+4 80%… +10 25%；失敗不降級；5 鑽石保證成功。
- 穿透來源：帽子（4% / 6.4% / 8.8%）、戒指（5% / 8% / 11%），乘上稀有度與強化，總上限 90%。

## 如何重新模擬

開發模式（`npm run dev`）或網址加 `?debug`，在主控台：

```js
const g = __game, s = g.state;
g.setAuto(true);
g.debugAdvance(600, 1 / 30); // 快轉 10 分鐘（不渲染）
console.log(s.level, s.stats.kills, s.stats.deaths);
```

`__inv` 提供背包函式（`equip`、`sellJunk`、`enhance`、`itemScore`…），可寫自動換裝的腳本。

## 爆擊與首領強度自動調整（v1.55.0）

### 爆擊

以前的問題：爆擊率 / 爆傷跟攻擊一樣吃「稀有度 × 強化」倍率（史詩 +10 = ×3.96），而神話裝會把屬性補到「同階標準裝戰力 ×1.08」，
爆傷在戰力評分裡很便宜（+100% 爆傷 = 40 攻擊），後期被放大好幾倍。結果：一身「狂暴」神話裝的弓手 / 狂戰士 / 劍俠爆傷 ×19、期望傷害 ×10。

修正：
- 爆擊率、爆傷只吃倍率超過 1 的部分的 40%（`CRIT_RARITY_DAMP`）：史詩 +10 → ×2.18、稀有 +6 → ×1.61。
- 神話裝的百分比額外屬性照原值給、最多佔預算一半，剩下的預算才放大主屬性（`items.ts` 的 `namedStats()`）。
- 上限：爆擊率 60%、爆傷 ×3.0（含道具增益；`CRIT_RATE_MAX` / `CRIT_DMG_MAX`）。
- 職業基礎不變（法師 / 騎士 / 召喚師 5% ×1.5、訓獸師 7% ×1.55、狂戰士 8% ×1.7、弓手 10% ×1.6、劍俠 12% ×1.7），偏爆擊的職業仍然比較高。

### 首領強度自動調整（`systems/BossScaling.ts`）

目標：不論等級、裝備、道具，首領戰平均約 180 秒，而且不可能速殺。

1. **攻擊力**（開戰決定）：和「該層標準配備＝首領等級、掉落階級精良 +2」比，玩家每被打一下掉的血量比例較低時，往標準配備的比例提高（加成取一半，最多 ×2）；所有首領再 ×0.85（戰鬥變長，挨打次數變多）。
2. **生命**：開戰時依「每下期望傷害 ÷ 標準配備」的 0.9 次方先放大；戰鬥中每秒用最近 20 秒的實際輸出預測剩餘時間，比目標快就放大（每秒最多 ×1.08）、慢很多就縮小（每秒最多 ×0.95，最低原本的 50%）。血條百分比不變，只是掉得快慢不同。最後 15 秒、剩 6% 以下不再調整。
3. **硬下限**：開戰 t 秒時首領至少還剩 1 −（t + 6）/ 150 的血，超過的傷害被擋下 → 不可能在 150 秒內打倒。
4. 首領脫戰 / 重生時恢復原本數值；被調整過時血條顯示「⚖ 依實力調整」。

破關評價配合調整：標準時間 80 → 210 秒、被招式打中每次 −6 → −4、用藥每個 −2 → −1.5。

## 首領脫戰與 AUTO 閃招修正（v1.61.0）

之前偶發的 300～420 秒首領戰（弓手、法師、召喚師）**不是職業太弱**，有兩個原因：
1. **首領被拖出場地、回滿血重打**：AUTO 閃招只往最近的出口閃，越閃越遠，首領離出生點超過 32 公尺（或玩家被拖到 32 公尺外）就脫戰回滿血。修正見 CHANGELOG v1.61（首領脫戰看玩家、首領往中央退、AUTO 往中央閃）。修正後首領離出生點 1～6 公尺（原本最多 25～33 公尺），脫戰 0 次。
2. **模擬計時包含「AUTO 不肯開打」的等待**：第三層首領 Lv15、模擬用 Lv14，AUTO 會略過比自己高等的首領，站著等首領走過來（等 10～111 秒）。第三層之前 190～290 秒其實都是這段等待。AUTO 改成只略過高 3 級以上的首領（`AUTO_BOSS_LEVEL_GAP` 2），模擬也改成記錄「開戰後秒數」。
