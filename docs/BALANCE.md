## 裝備

- 掉落率：小怪 18%（普通 60 / 精良 28 / 稀有 10 / 史詩 2）；首領必掉 2 件精良以上（精良 50 / 稀有 38 / 史詩 12）。
- 稀有度倍率：普通 1.0、精良 1.3、稀有 1.7、史詩 2.2。強化每 +1 全屬性 +8%。
- 強化成功率：+1~+2 100%、+3 90%、+4 80%… +10 25%；失敗不降級；5 鑽石保證成功。
- 穿透來源：帽子（4% / 6.4% / 8.8%）、戒指（5% / 8% / 11%），乘上稀有度與強化，總上限 90%。

## 如何重新模擬

開發模式（`npm run dev`）或網址加 `?debug`，在主控台：

```js
const g = __game, s = g.state;
g.setAuto(true);
g.debugAdvance(600, 1 / 30); // 快轉 10 分鐘（不渲染）
console.log(s.level, s.stats.kills, s.stats.deaths);
```

`__inv` 提供背包函式（`equip`、`sellJunk`、`enhance`、`itemScore`…），可寫自動換裝的腳本。
