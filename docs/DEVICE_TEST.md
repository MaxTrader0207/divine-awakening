## 2. 觸控手感
- [ ] 搖桿：從畫面左下任何位置按下都能出現，放開會停，斜方向不卡
- [ ] 技能按鈕：連點不會漏按，按住技能時移動不會中斷
- [ ] 雙指開合縮放鏡頭，不會誤觸技能
- [ ] 快捷道具欄（3、4 格）、AUTO 按鈕、暫停鍵都點得到、不會跟搖桿重疊
- [ ] 左手模式（設定）位置正確
- [ ] 震動回饋（設定開啟時）被打、放大招有震動

## 3. 畫面與排版（直式 / 橫式各看一次）
- [ ] 劉海 / 動態島 / 底部手勢條沒有擋住血條、技能、選單按鈕
- [ ] 選單每個分頁能捲動到底，最下面的按鈕點得到
- [ ] 手機旋轉：直式 ↔ 橫式自動切換，介面沒有錯位（設定可鎖定方向）
- [ ] 系統字型放大（輔助功能）時文字沒有互相重疊
- [ ] 首領血條、破關畫面、結局畫面完整顯示

## 4. 這幾版的新東西（v1.88～v1.96）
- [ ] 忍者：影分身出現時兩個影子跟著出刀

- [ ] 地圖景觀：地面、邊界、飄落粒子正常，沒有閃爍或黑塊
- [ ] 寶箱：走近會打開、10 分鐘內重新整理不會重生；AUTO 會順路去開（附近 22 公尺內、沒敵人時）
