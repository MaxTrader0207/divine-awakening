# App 版（.apk / .aab）追加項目（v1.112）

安裝方式：GitHub → Actions → Build Android → 下載 `divine-awakening-debug-apk`，傳到手機安裝（要允許「安裝未知來源」）。
上面第 1～6 節照樣測一次（「瀏覽器」欄填 App），再加下面這些。

## 已用模擬環境預先確認（2026-11-24，無頭瀏覽器＋假的 Capacitor 橋接）
- 6 種螢幕（360×640、360×800、384×824、412×915、673×841 摺疊、800×1280 平板）× 橫式（v1.113 重測 640×360～1280×800）：所有按鈕、狀態框、小地圖、技能、藥水都在安全區內，沒有小於 32px 的按鈕。
- 啟動時呼叫隱藏系統列、註冊返回鍵 / 背景 / 前景事件；回到前景會再隱藏一次系統列。
- 返回鍵：選單開著 → 關選單；遊戲中 → 暫停；暫停中 → App 縮到背景。
- App 版沒有註冊 Service Worker；設定頁顯示「✓ App 已內建全部檔案」。
- CPU 降速 6 倍下每幀邏輯 1.5～3.5 毫秒；draw call 72～117；三角形 低畫質 4.5～8.2 萬、高畫質 8.7～19.9 萬（雅典城最重）。GPU 幀數模擬不出來，要看實機。

## 7. 只有實機才測得到的（請逐項打勾）
- [ ] 安裝後圖示是法師帽（圓形 / 方圓形遮罩都沒有被切到），啟動畫面是深色底＋圖示，沒有白畫面閃一下
- [ ] 第一次啟動到看到開頭畫面幾秒：＿＿（目標 5 秒內）
- [ ] 全螢幕：狀態列、導覽列都隱藏；從邊緣滑出系統列後幾秒會自動收回，不會把畫面往下推
- [ ] 劉海 / 挖孔：左橫時小地圖、右橫時選單按鈕與技能鍵沒有被擋（兩個方向都看）
- [ ] 窄螢幕（寬 800 以下，例如 720p 的 20:9 手機）：下方角色面板沒有壓到搖桿或 Q 技能鍵；介面大小調到 120% 再看一次
- [ ] 開頭畫面（左邊標題、右邊存檔清單可以捲）與選職業（四欄，可以上下捲）正常
- [ ] 返回手勢（從左右邊緣滑）：關選單 → 暫停 → 回桌面；**玩的時候搖桿往左下推不會誤觸返回**
- [ ] 回桌面再點圖示回來：停在暫停畫面、進度還在、音樂沒有變兩層
- [ ] 從「最近使用」滑掉 App 再開：進度是滑掉前的（切到背景時有存檔）
- [ ] 來電、鬧鐘、通知下拉時自動暫停，結束後聲音恢復
- [ ] 放著不動 2 分鐘螢幕不會變暗；AUTO 掛機 10 分鐘不會黑屏
- [ ] 震動回饋有作用（設定開啟時被打、放大招）
- [ ] 飛航模式下可以開啟並遊玩；連回網路後雲端存檔 / 排行榜正常（「📴 離線」標籤消失）
- [ ] 移除 App 重裝：本機存檔會不見是正常的；有登入雲端的話可以取回
- [ ] 藍牙耳機：音效延遲可以接受、拔掉耳機不會突然外放很大聲
- [ ] 分割畫面 / 彈出視窗（三星、平板）：版面跟著縮放，不會整頁重新載入
- [ ] 舊機（Android 7～9）：能開啟、模型有載入（主控台沒有 `[Assets]` 警告；debug 版可用電腦 Chrome 的 `chrome://inspect` 看）
